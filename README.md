# AdBlock

Правила блокировки рекламы для встроенных браузеров [Browser](https://github.com/ladno1ife/Browser) и ZettelChat.
Приложения скачивают файлы отсюда и подхватывают изменения без выпуска новой версии.
Если файл удалить, приложение вернётся к своей встроенной копии.

| Файл | Что делает | Кто использует |
|---|---|---|
| `hosts.txt` | Рекламные и следящие домены, по одному на строку; поддомены блокируются тоже. `#` — комментарий. | Browser, ZettelChat |
| `vk.js` | Пропуск рекламы в VK Видео: жмёт «Пропустить», глушит и перематывает рекламный ролик. | Browser, ZettelChat |
| `yt.js` | Без рекламы на YouTube: убирает рекламу из данных плеера, пропускает ролик, если он всё же играет, прячет рекламные карточки. | Browser |
| `focus.js` | Меньше отвлекающего в VK и YouTube: без Клипов и Shorts, без главной, под видео только плеер. | ZettelChat |
| `mini.js` | Окно видео поверх заметок: на странице остаётся только плеер. | ZettelChat |

Файлы берутся по прямым ссылкам вида
`https://raw.githubusercontent.com/ladno1ife/AdBlock/main/hosts.txt`,
поэтому репозиторий должен оставаться открытым.
